# Ternary Loom

**Author: j-mosij**

![mini hex](docs/mini-hex.svg)

Balanced ternary codex `{-1, 0, 1}`.

The three parts interweave. When the mutual relation holds, the protection vehicle is summoned. Compression is the open reduction of a verified tryte to its source pair.

- A, B = source
- C = open shell (integrity only)
- Vehicle = static container that double-checks and never writes
- No dynamic code. No mid-build mutation.

```bash
python3 ternary_loom.py
```

Pure Python. Zero runtime dependencies.
